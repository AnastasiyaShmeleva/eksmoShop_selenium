# 🛒 Eksmo Shop UI Test

Это итоговый проект по автоматизации **UI** интернет-магазина издательства [Эксмо](https://eksmo.ru/) на языке **Python** с использованием **Selenium**.

---

## 🎯 Цель проекта

Проверить основной **user flow**: фильтры, сортировка, добавление товаров в корзину, оформление заказа и авторизация.

---

## 📝 Описание теста

Тест покрывает следующие шаги:

1. **Открытие главной страницы**
2. **Переход к разделу книг**
   - Наведение на раздел "Книги"
   - Переход на страницу "Энциклопедии для детей"
3. **Выбор фильтров**
   - По популярности: "Книги со скидкой", "Благотворительность"
   - По наличию: "В наличии"
   - По цене: минимальная цена увеличивается стрелкой, максимальная вводом текста
   - По серии: поиск через ввод текста, выбор двух серий
4. **Сортировка результатов**
   - По цене: "Сначала дешевые"
5. **Добавление товаров в корзину**
   - Добавление двух товаров
6. **Проверка корзины**
   - Проверка названий и цен товаров с каталогом
   - Проверка итоговой стоимости
7. **Оформление заказа**
   - Переход на страницу оформления
   - Авторизация по email и паролю
   - Проверка итоговой стоимости
8. **Скриншот**
   - Создание скриншота страницы оформления
